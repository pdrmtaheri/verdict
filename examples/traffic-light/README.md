# Four-way traffic light playground

    bun /path/to/verdict/src/cli.ts playground examples/traffic-light

Open the printed URL, connect your agent with the printed `claude mcp add` command,
and ask it: "Read the brief and build this playground." Watch the Preview panel fill
in, then the laws go from NOT PLANNED to PASS.

A good moment to try: after everything passes, ask the agent to swap yellow and the
all-red gap in the controller, and watch the checks catch it.
